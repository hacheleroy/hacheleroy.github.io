# Henri Leroy — academic website

This folder is a complete static website for `https://hacheleroy.github.io/`. It does not require a build tool, a theme, or any coding software.

## Publish it on GitHub Pages

1. Sign in to GitHub and create a new **public** repository named exactly `hacheleroy.github.io`.
2. In the empty repository, choose **Add file → Upload files**.
3. Upload the **contents** of this folder: `index.html`, `styles.css`, `.nojekyll`, and the `assets` folder.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`, and save.
7. Your website will appear at `https://hacheleroy.github.io/`. The first publication can take several minutes.

## What is included

- A simple, responsive academic profile with a compact sidebar and conventional sections
- Research themes, selected publications, education, experience, awards, teaching, and contact details
- Direct links to Google Scholar, GitHub, articles, the NSI preprint, and its code
- A downloadable PDF CV
- Search and social-sharing metadata
- No analytics, cookies, external fonts, or third-party JavaScript

## Updating the site later

Replace the relevant file on GitHub and commit the change. For content or design edits, you can also give this package back to ChatGPT with the requested changes; no manual coding is required.

The public site intentionally omits the telephone number from the CV. It uses the current EPFL affiliation and institutional email supplied by Henri Leroy.
